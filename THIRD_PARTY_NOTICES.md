## Questie and QuestieDB data

`data/classic-quests.json` contains quest names, objective descriptions, and
metadata imported from [QuestieDB](https://github.com/Questie/QuestieDB) at commit
`36ca1ca86f6c1838de479c7c7452eb0a57d5c135`, plus quest classifications imported
from [Questie](https://github.com/Questie/Questie) version 12.0.4.
`QuestCategories.lua` contains a generated lookup derived from those
classifications. Exact input paths and checksums are recorded in the catalog
and import scripts.
